## 表达边界

1. 可提供的交付范围是基于已有实现提出的合作入口，不等于已在客户生产中完成验收。
2. 在线工作台与本地服务明确分开。浏览器检索使用合成资料和词法/摘录；报告检查器不启动网关；视频工作台播放已有样片，不在浏览器执行渲染。
3. RAG 不宣传已接入生成模型、生产 SSO 或零幻觉；Relay 不证明真实模型身份；视频文件完整性不代替人工审片。
4. GEO 企业参与、公开原型和独立内容实验分别说明。人工发布凭证不等于平台回执，页面演示不证明 AI 收录、引用、排名或转化提升。
5. Eval 的规则结果不等于模型语义质量或业务验收；Thought-to-X 的九段提示结构不等于九个独立 Agent 或自动评审闭环。
6. 教育与参与经历沿用已有公开信息。未加入私人记忆、未授权客户资料、客户 Logo、收入、推荐语或虚构照片。
