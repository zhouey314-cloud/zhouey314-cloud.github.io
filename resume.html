Enterprise RAG Starter

知识检索

把分散资料变成带来源、可核查的检索结果。

Python · SQLite / FTS5 · JavaScript

  • 实现 MD / PDF / DOCX 入库，记录文件哈希、版本与生效日期，支持更新、删除及 SQLite 备份恢复。
  • 检索前按保存的租户与角色过滤资料，返回带版本、页码或段落的摘录；证据不足、缺值与冲突时明确拒答。
  • 用合成回归检查检索、引用与拒答，保留失败样本、健康检查和独立恢复命令，让结果可追查、服务可维护。

公开页使用合成资料做词法检索与原文摘录；未配置 LLM，范围选择不是生产鉴权。本地文件与身份库独立运行。

RelayAudit / AgentGuard

接口排障

把连接、响应与中断分开记录，让接口异常有据可查。

Python · HTTP / JSON / SSE · 回归检查

  • 实现连接固定上游的本地网关，分离请求转发、协议观察、告警与报告；默认被动模式不额外发起模型请求。
  • 处理 HTTP / SSE、超时、取消与背压；为在途请求和流式连接设置容量上限，超限明确返回 503。
  • 用合成对照与回归核查实体一致性、终止原因和超限恢复，保留监测降级状态与性能开销，便于定位和复现问题。

已验证本地与模拟链路；报告记录可观察的协议事实，模型身份保持未验证。
