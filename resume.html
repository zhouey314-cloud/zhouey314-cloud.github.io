Enterprise RAG Starter

知识检索

Python · SQLite / FTS5 · JavaScript

  • 实现 MD / PDF / DOCX 入库、文件哈希、版本与生效日期管理，以及文档更新和删除。
  • 本地服务在检索前过滤已保存的租户与角色，返回带版本、页码或段落的原文摘录，对证据不足与冲突资料明确拒答。

RelayAudit / AgentGuard

链路观测

让 Agent 的协议异常与服务变化有迹可查。

Python · HTTP / JSON / SSE · 回归检查

  • 实现连接固定上游的本地网关，分离请求转发、协议观察、告警与报告；默认被动模式不额外发起模型请求。
  • 处理流式响应、超时、取消、背压和并发等情况，保留实际终止原因与监测降级状态。
  • 公开受控测试与直连、仅代理、完整观测的对照记录，检查实体一致性，同时呈现实际性能开销。

已验证本地与模拟链路；不作为真实上游模型身份的鉴定工具。

AI Video Workflow Engine

内容工程

把视频制作变成可以复现、检查和交接的流程。

Python · FFmpeg · 工作流状态机 · 媒体 QA

  • 连接素材检查、时间轴、字幕、渲染与质量检查，用状态机覆盖素材缺失、输出失败和恢复路径。

已有可播放程序动画；不作为真人口播、数字人或客户商业成片的验收证明。
