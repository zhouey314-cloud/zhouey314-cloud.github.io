新公开作品 / RelayAudit / AgentGuard

让 Agent 中转链路里的异常，有迹可循。

开源 0.2.0 / 本地模拟链路与协议检查

目前不具备经过校准的真实模型身份识别能力；所有模型身份状态保持未验证。

01这是什么

Agent 仍然正常使用，网关只观察可见信息。

项目让 Agent 请求经本地网关转发到用户配置的 API，默认 passive 模式不会额外发送模型请求。它观察声明标签、协议错误和服务变化，独立输出告警和报告。

02看结果

已经有可复现的合成链路演示。

公开 README 提供模拟 Agent 与模拟中转的调用：正常请求、标签改变、触发告警，以及后续请求继续完成。这个演示证明告警路径，不证明真实中转商更换了模型。

03我做了什么

拆出协议观察、证据、告警与恢复流程。

公开仓库提供协议检查、流式数据保真、本机通知、状态管理、报告和受限配置方式。演示环境及测试记录可从仓库复核；本站不重跑模型服务。

04一项关键选择

不把“异常”误写成“识别到假模型”。

模型声明变化只是标签不符合预期；协议错误可能来自网关、模型或参数；性能变化是描述性现象。即使可见标签不变，也不能据此证明真实模型身份。

05成果与限制

已经跑通模拟检测，真实模型身份仍未校准。

真实客户端连到模拟端点有接入验收；尚无真实中转站模型身份指纹与校准准确率。数据不足应当显示数据不足。被动模式不等于零延迟，开启复核请求也不等于金额硬预算。
