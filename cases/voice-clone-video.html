让配音从授权开始，而不是从生成开始。

开源本地 CLI / 离线 Mock / 人工审听

模拟运行使用静音测试素材；不代表完成真实克隆或音色质量验收。真实模式须获得明确授权。

01这是什么

先确认声音能否使用，再谈自动化。

这个本地工作流以经过明确许可的录音为前提。创建音色时检查授权文件、用途与有效期；复用已有音色前，仍需使用者确认授权持续有效。未经授权的声音不得上传或生成。

02看结果

一条字幕，对应一段可核查的声音。

SRT/VTT 的每个 cue 对应独立合成音频和时间轴；合成后再通过 FFmpeg 生成可复核的视频输出。公开仓库提供合成字幕示例与不调用外部 API 的 Mock。

03我做了什么

把授权门禁和时间轴拆成独立步骤。

公开仓库包含 Python CLI、字幕时间轴、录音检查、MiniMax 客户端接口、FFmpeg 合成和 JSON/Markdown 报告，不需要另起一个网站后台。

04一项关键选择

自动生成和自动发布是两回事。

即使输出视频，状态也停在待人工观看和试听；出现音频时长溢出、授权不足或外部服务阻断时应明确停止。

05成果与限制

离线工具可检查，不等于真实音色表现。

Mock 流程输出静音测试素材并标记 DEMO_ONLY；它能帮助检查时序和软件逻辑，但不能证明真实声音自然度、外部 API 可用性或商业级视频质量。

06深入查看

源代码与运行说明可完整查阅。

真实音频会上传至第三方语音服务，需由使用者确认知情授权、适当披露、保存期限和费用。网站不提供模拟真实人物声音的入口。
