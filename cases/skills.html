01 / Problem

智能体任务说明经常是宽泛提示，缺少输入、输出、失败路径和人审边界，难以复用或评估。

02 / Context

这是一组公开、独立、单用途的 Agent Skill 文档；目标是让陌生开发者能 clone、阅读、复制并修改。

03 / Constraints

纯 Markdown 工作流不自动获得工具权限；公开示例是虚构的 synthetic_unverified，不能当作模型质量证明。

04 / Architecture

十个 SKILL.md 共享 Purpose、When to Use、Inputs、Outputs、Workflow、Failure Handling、Example、Tests、Limitations 合同；Python 校验器独立于模型运行。

05 / Implementation

添加统一前言与失败路径、三份合成 walkthrough、贡献说明、变更日志、Issue 模板、CI 和评估规范。

06 / Demo

克隆主分支，运行 python3 tests/validate.py 与 python3 evals/run.py；结果只验证合同结构和合成案例 schema。

07 / What Worked

十个 Skill 的结构检查和三个合成评估夹具校验通过；CI 检查通过。

08 / What Failed

尚未用独立人工真值运行 provider-backed 模型行为评估；无法声称真实任务成功率或用户采用。

09 / Lessons

可复制的提示词合同与可验证的模型表现是两件事；发布说明必须区分它们。

10 / Next Steps

用获授权的小样本任务进行人工审核，记录失败案例并建立回归集，然后再决定哪些 Skill 值得扩展。
