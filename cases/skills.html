01这是什么

智能体任务说明经常是宽泛提示，缺少输入、输出、失败路径和人审边界，难以复用或评估。

这是一组公开、独立、单用途的 Agent Skill 文档；目标是让陌生开发者能 clone、阅读、复制并修改。

02看结果

十个单用途 Skill 用统一结构描述输入、输出、步骤与失败路径。

查看公开材料 ↗

03我做了什么

添加统一前言与失败路径、三份合成 walkthrough、贡献说明、变更日志、Issue 模板、CI 和评估规范。

展开技术结构

十个 SKILL.md 共享 Purpose、When to Use、Inputs、Outputs、Workflow、Failure Handling、Example、Tests、Limitations 合同；Python 校验器独立于模型运行。

04一项关键选择

每个 Skill 保持单用途；缺少来源、所有者或发布授权时明确失败。虚构示例统一标为 synthetic_unverified。

05成果与限制

十个单用途 Skill 用统一结构描述输入、输出、步骤与失败路径。

公开示例为 synthetic_unverified。合同校验不代表模型质量或真实使用效果；文档不会授予工具权限。

不同 Agent Host 的触发方式不保证一致；Skill 文档不会授予工具权限，也不能证明客户采用。

06深入查看

离线校验检查 Skill 合同和合成案例 schema；未运行有独立人工真值的模型行为评估。

检查范围与下一步

离线检查不调用模型；没有人工确认的真实案例、provider 输出或可报告的任务成功率。

用获授权的小样本任务进行人工审核，记录失败案例并建立回归集，然后再决定哪些 Skill 值得扩展。
