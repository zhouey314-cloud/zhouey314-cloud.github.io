01这是什么

想法是自己的，表达却还很乱。

Thought-to-X 是一个可复用的写作工作流和 Python CLI：先提取真实意图，再组织结构、调整语气，最后交给作者复核。

02看结果

“命运与选择”是项目已有的公开示例。它保留了电影比喻、命运与行动之间的张力，也保留了作者的不确定。

看三个分镜 ↗

03我做了什么

把想法提取、结构整理、语气保留和人工检查组装成可复用的流程，并整理模块化提示词、CLI、Provider 边界、公开示例和离线测试。

展开运行方式

--prompt-only 只组装工作流，不调用 API。可选的 OpenAI-compatible Provider 需要另外配置；网站本身不运行模型。

工作流的原文件和使用说明都在项目仓库中。

04一项关键选择

先保留“我想说什么”，再优化“怎么说”。

流畅不一定忠于原意。公开示例保留“可能”“不知道”，不把个人猜想包装成确定事实。

05成果与限制

仓库提供工作流、CLI 和可阅读的完整示例，便于查看每一步如何从原始材料走到文稿。

需要作者最终复核，不自动发布到 X。公开示例不能证明对所有人的声音保留程度，也不保证传播效果。

离线测试检查 Prompt 组装和 CLI 行为；尚无独立人工评分的模型质量基准。
