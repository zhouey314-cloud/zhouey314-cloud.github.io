01 / Problem

共享知识流程容易在租户、角色和审核状态之间串线。

02 / Context

构建一个可操作的多租户工作流演示，把共享策略、审批状态和可见范围放在同一条路径里。

03 / Constraints

浏览器 Demo 的口令只是角色选择器，不是身份认证；样本租户和内容均为虚构。

04 / Architecture

Node.js 的策略核心与浏览器状态界面分离；权限和状态转换由测试覆盖。

05 / Implementation

实现租户隔离、角色操作、审批/发布状态与可见性说明；公开演示允许按角色走通路径。

06 / Demo

可运行入口：https://zhouey314-cloud.github.io/multi-tenant-ai-workflow-saas/。这是公开演示/样本，不等于生产部署或用户验收。

07 / What Worked

离线规则可验证；页面能展示边界而非只给截图。

08 / What Failed

没有真实 SSO、持久化服务或生产权限审计；演示口令不能抵御恶意用户。

09 / Lessons

把权限断言和状态机测试提前，降低 UI 看起来正确但跨租户泄漏的风险。

10 / Next Steps

如进入真实环境，需加入后端鉴权、真实租户数据隔离和安全审计。
