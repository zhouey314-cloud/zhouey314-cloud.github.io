Recruitment Review

招聘辅助工具容易把不透明分数当作自动决定，导致无法解释和复核。

Open Demo / Evidence ↗Repository ↗
ROLE个人自建 / 工程实现与验证
EVIDENCE13 单测、5 合成夹具、36 组跨端对照。
BOUNDARY没有真实简历、真实候选人或招聘效度证明；不自动录用或拒绝。

01 / Problem

招聘辅助工具容易把不透明分数当作自动决定，导致无法解释和复核。

02 / Context

构建虚构候选人的审核演示，把证据、规则分数和人工决定分开。

03 / Constraints

没有真实简历、真实候选人或招聘效度证明；不自动录用或拒绝。

04 / Architecture

Python 规则与浏览器演示保持一致，人工闸门对最终决定负责。

05 / Implementation

合成夹具、风险说明、审阅界面与 Python/浏览器对照验证。

06 / Demo

可运行入口：https://zhouey314-cloud.github.io/ai-recruitment-workflow-demo/。这是公开演示/样本，不等于生产部署或用户验收。

07 / What Worked

可追踪规则输入并保留人审边界。

08 / What Failed

规则分数不能说明对真实人群的公平性或预测有效性。

09 / Lessons

高风险决策应先建人审和证据链，不应把 Demo 分数包装成招聘判断。

10 / Next Steps

需要合规审查、获授权数据、偏差评估和人工验收后才谈真实试点。
